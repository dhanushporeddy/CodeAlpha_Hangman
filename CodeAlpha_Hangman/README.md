# 🎯 CodeAlpha Hangman Game

A console-based Hangman game developed in Python as part of the CodeAlpha Python Programming Internship.

## 📌 Project Overview

This project is a text-based Hangman game where the player attempts to guess a randomly selected word one letter at a time.

The player gets a maximum of 6 incorrect guesses. The game keeps track of guessed letters, remaining lives, and the player's score.

## ✨ Features

- 🎲 Random word selection
- 🔤 Five predefined words
- ❤️ Six incorrect guesses allowed
- 🕵️ Hidden word display
- ⚠️ Duplicate letter detection
- ✅ Input validation
- 💀 Visual Hangman stages
- 🏆 Score calculation
- 🔄 Replay option
- 🚪 Exit option
- 💻 Simple console interface

## 🛠️ Technologies Used

- Python 3
- Random module
- Object-Oriented Programming
- Strings
- Sets
- Lists
- Loops
- Conditional statements
- Functions

## 🎮 How to Play

1. Run the Python program.
2. The game randomly selects a word.
3. Enter one letter at a time.
4. Correct letters are revealed in the hidden word.
5. Incorrect letters reduce the available lives.
6. Guess the complete word before using all 6 incorrect guesses.
7. Type `EXIT` to leave the game.
8. After a round, choose `Y` to play again or `N` to exit.
